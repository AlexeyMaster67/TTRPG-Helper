# WBmd: Архитектурная спецификация (Technical Specification)

---

## 1. Обзор архитектуры

Модуль **WBmd** представляет собой встроенную в TTRPGHelper подсистему для ведения кампаний, создания лора и заметок мастера.

### 1.1. Базовые принципы
1. **Plain-Text Markdown (`.md`) на диске**:
   - Пользователь выбирает папку (Vault) на своем компьютере через нативный диалог Tauri.
   - Любые изменения сохраняются в виде стандартных текстовых файлов `.md` с Frontmatter в формате YAML.
   - Пользователь может в любой момент открыть эту папку в Obsidian, VS Code, Typora или Chronicler.
2. **Нулевой vendor lock-in**:
   - Никаких проприетарных баз данных для хранения текста. Заметки остаются независимыми файлами.
   - Метаданные хранятся внутри самих файлов в блоке `--- ... ---`.
3. **Реактивный индекс и Граф в памяти**:
   - В фоновом потоке/сервисе работает легковесный индексатор `vaultIndexer`, сканирующий файлы, строящий граф прямых и обратных связей (Backlinks), список тегов и сущностей.
4. **Бесшовная синергия с TTRPGHelper**:
   - Вызовы бестиария, запуск инициативы, броски кубиков и трансляция на экран игроков работают прямо из текста заметки.

## 3. Спецификация формата заметок (WBmd Markdown Standard)

Каждая заметка — это стандартный валидный Markdown-файл с расширениями, безопасными для сторонних парсеров (graceful degradation).

### 3.1. YAML Frontmatter (Метаданные)
```yaml
---
title: "Элдрин Шепчущий"
type: npc
avatar: "портрет_элдрина.jpg"
tags: [эльф, маг, информатор, арфисты]
status: alive
location: "[[Порт Найанзару]]"
faction: "[[Арфисты]]"
cr: 6
custom_fields:
  "Мировоззрение": "Хаотично-добрый"
  "Секретный пароль": "Полуночный ворон"
---
```

### 3.2. Расширения синтаксиса WBmd

| Синтаксис | Назначение | Пример | Рендеринг в режиме чтения | Поведение при отправке на экран игроков |
|---|---|---|---|---|
| `[[Страница]]` | Внутренняя ссылка | `[[Порт Найанзару]]` | Интерактивная ссылка с ховер-превью | Обычная ссылка или выделенный текст |
| `[[Страница\|Текст]]` | Ссылка с алиасом | `[[Порт Найанзару\|Город купцов]]` | Отображает «Город купцов» со ссылкой | Отображает текст «Город купцов» |
| `[[Страница#Раздел]]` | Ссылка на заголовок | `[[Правила#Отдых]]` | Скролл к конкретному заголовку | Скролл к заголовку |
| `![[картинка.png]]` | Вставка изображения | `![[карты/город.png]]` | Встроенное адаптивное изображение | Показывается на экране игроков |
| `@monster:Имя` | Интерактивный монстр | `@monster:Goblin Boss` | Бейдж монстра с кнопкой «В бой» и ховером статблока | Отображается как название без скрытых статов |
| `@spell:Имя` | Интерактивное заклинание | `@spell:Misty Step` | Всплывающая карточка заклинания | Всплывающая карточка заклинания |
| `@item:Имя` | Интерактивный предмет | `@item:Bag of Holding` | Всплывающая карточка предмета | Карточка предмета |
| `@char:Имя` | Ссылка на члена партии | `@char:Торин` | Бейдж персонажа с показателем текущего HP | Бейдж персонажа |
| `dice:NdX+M` | Интерактивный бросок | `dice:1d20+5` или `dice:2d6` | Кликабельная кнопка броска кубика | Скрыт или отображается как результат |
| `\|\|текст\|\|` | Инлайн-спойлер мастера | `\|\|Под ковром люк\|\|` | Заблюренная плашка, открытие по клику | **Полностью удаляется** при трансляции |
| `:::secret ... :::` | Блок секретов мастера | `:::secret DC 15 Скрытность::: ` | Рамка секретов GM | **Полностью удаляется** при трансляции |
| `{{insert: Страница}}` | Вставка другой заметки | `{{insert: Памятка_боя}}` | Встроенный рендер содержимого заметки | Рендерится безопасно |

## 4. Модель данных (TypeScript Interfaces)

```typescript
// Тип сущности в worldbuilding
export type WBEntityType = 'npc' | 'location' | 'faction' | 'quest' | 'item' | 'session' | 'lore' | 'custom';

// Метаданные заметки
export interface WBMetaData {
  title: string;
  type?: WBEntityType;
  avatar?: string;
  tags?: string[];
  aliases?: string[];
  created?: string;
  updated?: string;
  location?: string;
  faction?: string;
  custom_fields?: Record<string, string | number | boolean>;
  [key: string]: any;
}

// Заметка в памяти
export interface WBNote {
  id: string;               // Уникальный относительный путь от корня хранилища (напр. "01_NPC/Элдрин.md")
  fileName: string;         // "Элдрин.md"
  title: string;            // Заголовок из frontmatter или имя файла
  path: string;             // Абсолютный путь на диске
  content: string;          // Сырой Markdown контент (включая frontmatter)
  body: string;             // Тело документа без frontmatter
  meta: WBMetaData;         // Распарсенные метаданные
  outlinks: string[];       // Список целевых заметок, на которые ссылается документ
  backlinks: string[];      // Список заметок, которые ссылаются на этот документ
  tags: string[];           // Все теги документа (#tag и tags: [])
  modifiedTime: number;     // Таймстемп изменения
}

// Узел графа мира
export interface WBGraphNode {
  id: string;
  title: string;
  type: WBEntityType;
  tags: string[];
  linkCount: number;
}

// Ребро графа
export interface WBGraphEdge {
  source: string;
  target: string;
  relationType?: string;    // 'allied', 'located_in', 'member_of', 'generic'
}
```

## 5. Архитектура подсистем

### 5.1. Storage Engine (`wbStorageService.ts`)
- **Tauri FS Integration**:
  - Использование `@tauri-apps/plugin-fs` для чтения, записи, перемещения и удаления файлов и папок.
  - Нативный диалог выбора папки хранилища (`@tauri-apps/plugin-dialog`).
- **Web / Fallback Mode**:
  - Если запуск происходит в браузере (без Tauri), используется IndexedDB (или File System Access API), обеспечивая полную работоспособность во всех средах.
- **Auto-save & Debounce**:
  - Сохранение с задержкой 400 мс при вводе текста, защита от потерь при переключении вкладок.

### 5.2. Link & Index Engine (`wbIndexEngine.ts`)
- Сканирует все `.md` файлы в выбранной директории.
- Извлекает YAML Frontmatter через быстрый парсер.
- Парсит регулярными выражениями и AST все `[[Wikilinks]]`, `@monster`, `@spell`, `#tags`.
- Формирует двустороннюю карту ссылок: `Map<noteId, Set<targetId>>` и `Map<noteId, Set<backlinkId>>`.
- Резолвит неточные имена (напр. `[[Элдрин]]` связывается с `01_NPC/Элдрин Шепчущий.md`).
- Автоматически выполняет каскадный рефакторинг ссылок при переименовании файла.

### 5.3. Markdown Parser & AST Renderer (`WBMarkdownRenderer.tsx`)
- Чистый, производительный парсер без раздутых зависимостей.
- Поддержка стандартного GFM (заголовки, жирный, курсив, таблицы, списки задач, цитаты, код).
- Кастомные токены TTRPGHelper:
  - Токен `Wikilink`: компонент `<WBWikilink target="..." alias="..." />`
  - Токен `EntityBadge`: компонент `<WBEntityBadge type="monster|spell|item" id="..." />`
  - Токен `DiceBadge`: компонент `<WBDiceChip formula="1d20+5" />`
  - Токен `SecretBlock`: компонент `<WBSpoilerBlock />`
  - Токен `InsertBlock`: компонент `<WBPageInsert target="..." />`

### 5.4. Graph Visualizer (`WBGraphView.tsx`)
- Высокопроизводительный 2D Force-Directed холст (HTML5 Canvas или Konva / WebGL).
- Фильтрация по типам сущностей (только NPC и Локации, или все).
- Цветовая дифференциация узлов по типам.
- Клик по узлу — мгновенное открытие заметки в редакторе.

### 5.5. Player Broadcast Bridge (`wbBroadcastBridge.ts`)
- Функция `broadcastNoteToPlayerDisplay(note: WBNote)`:
  1. Клонирует контент заметки.
  2. Рекурсивно вырезает секции `:::secret` и синтаксис `||spoiler||`.
  3. Извлекает главное изображение (avatar/art).
  4. Формирует пакет `HandoutData` с `type: 'lore' | 'image' | 'npc'`.
  5. Отправляет через `broadcastService.broadcast({ type: 'HANDOUT_SHOW', payload: ... })`.
  6. На экране игроков отображается атмосферная стилизованная карточка или страница свитка без секретов мастера!

## 6. Пользовательский интерфейс (UI / UX)

### 6.1. Режимы отображения
1. **Wiki Workspace (Трехпанельный режим)**:
   - Левая панель: Дерево файлов и папок Vault, быстрый фильтр по тегам, кнопка «Новая заметка / папка».
   - Центральная панель: Двухрежимный редактор (Edit Mode / Live Preview / Split View).
   - Правая панель: Инфобокс сущности + вкладки (Обратные ссылки, Граф локальных связей, План сессии).
2. **Interactive Graph Mode**:
   - Полноэкранный интерактивный граф всей кампании с регуляторами масштаба, гравитации и поисковым фильтром.
3. **Map Pinboard Mode**:
   - Просмотр карты мира с интерактивными пинами заметок.

### 6.2. Верхняя панель инструментов редактора
- Кнопки быстрого форматирования (B, I, H1, H2, Таблица, Список).
- Инструменты TTRPG:
  - 🎲 **«Вставить кубик»** (`dice:...`)
  - 🐉 **«Привязать монстра»** (модалка выбора из бестиария с фильтром по CR)
  - 🧙 **«Привязать заклинание / предмет»**
  - 🔒 **«Секрет мастера»** (обернуть выделенный фрагмент)
  - 📺 **«Отправить на экран игроков»** (с предпросмотром того, что увидят игроки)
