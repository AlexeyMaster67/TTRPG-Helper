# План реализации модуля Worldbuilding (WBmd) для TTRPGHelper

---

## 🎯 Цель плана
Поэтапное проектирование и разработка автономной, быстрой и глубоко интегрированной подсистемы **WBmd** в TTRPGHelper, обеспечивающей ведение заметок, создание миров, вики-перелинковку и синхронизацию с сессией без нарушения чужой интеллектуальной собственности.

---

## Фаза 1: Хранилище и Файловая Система (Vault File Engine)

### Задачи:
1. **Разработка `wbStorageService.ts`**:
   - Интеграция с `@tauri-apps/plugin-fs` и нативным диалогом выбора директории `@tauri-apps/plugin-dialog`.
   - Поддержка операций: `openVault()`, `createNote()`, `readNote()`, `writeNote()`, `deleteNote()`, `renameNote()`, `createFolder()`, `deleteFolder()`.
   - Реализация Web-fallback режима (IndexedDB / File System Access API) для работы в веб-версии или тестах без Tauri.
2. **Создание хранилища состояния `wbStore.ts` (Zustand)**:
   - Состояние: `vaultPath`, `vaultName`, `notesTree`, `activeNoteId`, `activeNoteContent`, `isDirty`, `isSaving`, `searchQuery`, `viewMode`.
   - Защита от потери данных: механизм Debounce автосохранения (400ms) и обработчик закрытия окна `beforeunload`.
3. **Служебная структура `.wbmd/`**:
   - Автоматическое создание `.wbmd/config.json` в корне выбранного пользователем хранилища для сохранения пользовательских настроек (тема, шаблоны, пины).

---

## Фаза 2: Синтаксический Движок (TTRPG Markdown Parser & AST)

### Задачи:
1. **Парсер YAML Frontmatter**:
   - Безопасное выделение блока `--- ... ---` в начале файла, парсинг заголовка, тегов, типа сущности (`npc`, `location`, `faction`, `quest`), аватара и произвольных полей.
2. **Расширения синтаксиса для НРИ**:
   - `[[Wikilinks]]`: распознавание форматов `[[Имя]]`, `[[Имя|Алиас]]`, `[[Имя#Секция]]`.
   - `@monster:Name`: парсинг привязки к бестиарию TTRPGHelper.
   - `@spell:Name` и `@item:Name`: привязка к компендиуму заклинаний и экипировки.
   - `dice:1d20+5`: распознавание формул бросков кубиков.
   - `||секретный текст||`: распознавание инлайн-спойлеров.
   - `:::secret ... :::`: распознавание многострочных блоков секретов мастера.
   - `{{insert: Note Name}}`: распознавание директивы вставки фрагмента другой заметки.
3. **AST Рендерер компонентной модели React**:
   - Рендеринг чистого HTML с заменой специальных токенов на интерактивные React-компоненты:
     - `<WBDiceChip />`
     - `<WBMonsterBadge />`
     - `<WBWikilink />`
     - `<WBSpoiler />`
     - `<WBPageInsert />`

## Фаза 3: Пользовательский Интерфейс Редактора (WBmd Workspace UI)

### Задачи:
1. **Макет рабочей области `WBWorkspace.tsx`**:
   - Левая колонка (Sidebar):
     - Дерево папок и заметок с иконками типов (папка, NPC, локация, квест).
     - Кнопки быстрого создания заметки/папки.
     - Быстрый поиск и фильтр по тегам.
   - Центральная область (Editor & Preview):
     - Переключатель режимов: **Только редактор**, **Live Split** (редактор + предпросмотр), **Только чтение**.
     - Панель инструментов форматирования (Markdown кнопки + вставка кубика, монстра, секрета).
   - Правая колонка (Context Inspector):
     - Инфобокс сущности (с редактированием аватара, тегов и параметров).
     - Список обратных ссылок (Backlinks).
     - Быстрый мини-граф текущей заметки (Local Graph).
2. **Визуальный конструктор Инфобокса**:
   - Удобная модалка или боковая форма редактирования полей без необходимости вручную писать YAML.
3. **Адаптация под темную/светлую тему TTRPGHelper**:
   - Использование токенов `tokens.css` и `index.css` (Cinematic Dark, D&D Gold, Cyberpunk Neon).

---

## Фаза 4: Индексация, Wikilinks и Backlinks Engine

### Задачи:
1. **Реактивный индексатор `wbIndexEngine.ts`**:
   - Построение графа связей `outlinks` и `backlinks` при открытии хранилища и обновлении заметок.
   - Поддержка синонимов и нечетких путей (резолв `[[Гоблин]]` к файлу `Существа/Гоблин.md`).
2. **Всплывающий автокомплит при наборе**:
   - При вводе `[[` в редакторе открывается всплывающее меню с подсказками существующих заметок и заголовков.
   - При вводе `@monster:` открывается выпадающий список существ из базы данных с фильтрацией на лету.
3. **Безопасный рефакторинг при переименовании**:
   - При переименовании заметки диалог предлагает: *«Обновить ссылки в X документах?»*. Автоматическая замена всех упоминаний `[[Старое имя]]` на `[[Новое имя]]`.
4. **Диагностика сломанных ссылок (Broken Links Inspector)**:
   - Подсветка несуществующих ссылок красным цветом и возможность создать недостающую страницу в 1 клик.

---

## Фаза 5: Глубокая интеграция с TTRPGHelper

### Задачи:
1. **Интеграция с Боевым Трекером (`combatStore.ts`)**:
   - При наведении на `@monster:Ancient Red Dragon` открывается всплывающий статблок.
   - Кнопка **«Добавить в текущий бой»** сразу добавляет монстра в ростер инициативы `useCombatStore`.
2. **Интеграция с физикой 3D кубиков (`QuickDiceBar` / Cannon-es / Three.js)**:
   - Клик по `dice:2d8+3` в тексте заметки инициирует бросок с визуализацией и фиксацией в `combatLog`.
3. **Мост трансляции на Экран Игроков (`wbBroadcastBridge.ts`)**:
   - Кнопка на панели заметки: **«Транслировать игрокам»** (Send to Player Screen).
   - Автоматическая санитизация (удаление блоков секретов мастера и спойлеров).
   - Трансляция через `broadcastService` на второй экран в виде красивого свитка/иллюстрации без спойлеров сюжета.
4. **Интеграция с тактической картой (`mapStore.ts`)**:
   - Возможность привязать заметку локации к сохраненной сетке боевой карты.

---

## Фаза 6: Интерактивный Граф Знаний и Пинборд Карт

### Задачи:
1. **Интерактивный 2D Граф (`WBGraphView.tsx`)**:
   - Полноэкранный просмотр связей между всеми заметками мира.
   - Физическая модель отталкивания и притяжения узлов (Force-directed).
   - Цветовая дифференциация типов сущностей:
     - 🟣 Персонажи / NPC
     - 🟢 Локации / Города
     - 🟡 Фракции / Гильдии
     - 🔵 Квесты / Задания
     - ⚪ Общие заметки лора
   - Фильтрация по тегам и типам, поиск по графу, клик для перехода к заметке.
2. **Пинборд карт региона (`WBMapPinboard.tsx`)**:
   - Загрузка изображения глобальной карты кампании (Sword Coast, Night City и т.д.).
   - Размещение интерактивных кликабельных меток (пинов), ведущих к заметкам соответствующих локаций.

---

## Фаза 7: Шаблоны, Импорт/Экспорт и Тестирование

### Задачи:
1. **Библиотека стартовых шаблонов**:
   - Шаблон NPC (D&D 2024 / Cyberpunk RED / PF2e).
   - Шаблон Локации (Город, Подземелье, Таверна).
   - Шаблон Фракции (Организация, цели, ключевые фигуры).
   - Шаблон Дневника сессии (Цели, события, полученный лут, заметки на будущее).
2. **Импорт и совместимость**:
   - Прямое открытие существующих папок Obsidian или Chronicler без конвертации.
   - Экспорт всей кампании или отдельной заметки в PDF / Standalone HTML / Markdown архив.
3. **Модульные тесты**:
   - Тесты парсера AST (frontmatter, wikilinks, dice chips, secrets).
   - Тесты резолвера ссылок и механизма обновления при переименовании.
   - Тесты санитизации секретов при трансляции на экран игроков.

---

## 📌 Оценка готовности к реализации
Все архитектурные решения согласованы с общим стеком TTRPGHelper, не требуют сторонних платных зависимостей, обеспечивают 100% приватность данных пользователя и превосходят Chronicler и Obsidian по глубине интеграции с механикой проведения настольных игр.
