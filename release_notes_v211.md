# TTRPG Helper v2.1.1 — Система проверки обновлений и сетевая устойчивость

Релиз 2.1.1 внедряет встроенную подсистему проверки и установки обновлений через GitHub Releases API, сохраняя при этом 100% автономность и офлайн-приоритет приложения.

### Что нового в версии 2.1.1:

1. **Встроенная система обновлений (In-App Update System)**
   - Проверка новых версий через официальный GitHub API с 4-секундным жестким таймаутом (AbortController).
   - Интеллектуальное ограничение частоты автоматических проверок (не чаще 1 раза в 4 часа).
   - Возможность ручной проверки обновлений в любой момент во вкладке «Общие настройки».
   - Опция отключения фоновой проверки при запуске.

2. **Модальное окно обновления**
   - Наглядное сопоставление установленной и доступной версии.
   - Дата публикации и размер установочного файла.
   - Интегрированный список изменений релиза (Changelog) с удобной прокруткой.
   - Действия: прямое скачивание актуального инсталлятора, «Напомнить позже» и возможность пропустить конкретную версию.

3. **Сетевая устойчивость и безопасная изоляция офлайн-режима**
   - Реализован хук отслеживания статуса сети (useNetworkStatus).
   - Внешние ссылки сообщества Discord автоматически приглушаются и блокируются при отсутствии подключения к сети с информативной подсказкой без сдвигов верстки.
   - Актуализирована ссылка на официальный Discord-сервер (https://discord.gg/MGnjS3ceEh).

4. **Полная сохранность локальных данных**
   - Установка версии 2.1.1 поверх существующих сборок полностью сохраняет пользовательские базы данных SQLite, заметки Worldbuilding, карточки персонажей и токены.
