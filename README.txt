================================================================================
DnD_AIT — Автоматический трекер инициативы и боя (D&D 5e / редакция 2024)
Версия 1.0 (Standalone Win-x64 Release)
================================================================================

О ПРОГРАММЕ:
DnD_AIT — это специализированное десктопное приложение (.NET 8 WPF) для мастеров
подземелий (Dungeon Master) и игроков D&D, обеспечивающее управление боевыми
столкновениями, расчет тактической инициативы, интерактивную сетку карты, туман
войны для экрана игроков, механику состояний D&D 2024 и матрицу урона.

ОСНОВНЫЕ ВОЗМОЖНОСТИ:
1. Изоляция горячих клавиш:
   - Переключение хода пробелом (Space) работает глобально, но полностью изолировано
     от текстовых полей ввода (TextBox, ComboBox, PasswordBox).
   - Быстрый ввод урона и лечения: нажмите '+' (лечение) или '-' (урон) на клавиатуре
     (включая Numpad) при выбранном существе для открытия инлайн-оверлея.
     Ввод числа -> Enter (применить) / Esc (отмена).

2. Преимущество и помеха (D&D 5e / 2024 Advantage/Disadvantage):
   - Переключатель [Помеха] [Обычный] [Преимущество] в окне атаки и бросках.
   - Обычный: 1d20 + мод.
   - Преимущество: 2d20 (выбор наибольшего) с детальным логом [броски -> лучший].
   - Помеха: 2d20 (выбор наименьшего) с детальным логом.

3. Матрица урона и временные хиты:
   - Раздельный расчет урона по типам.
   - Сопротивления (урон делится пополам с округлением вниз).
   - Иммунитеты (полное сведение урона к 0).
   - Уязвимости (урон удваивается).
   - Временные хиты (Temp HP): поглощаются первыми, не складываются, замещаются
     только при превышении текущего значения.

4. Правила D&D 2024:
   - Спасброски от смерти при 0 ХП: получение урона начисляет +1 провал, крит начисляет
     +2 провала. При превышении урона MaxHp наступает мгновенная гибель.
     Натуральная 20 восстанавливает 1 ХП и стабилизирует существо.
   - Легендарные действия монстров восстанавливаются строго в начале хода этого босса.
   - Концентрация: при получении серии атак проверка спасброска Телосложения
     (максимум из 10 или половины полученного урона) генерируется для каждого попадания.
   - Все 16 официальных состояний D&D 2024, включая состояние «Ошеломлённый» (Dazed).

5. Мультиатака без модального ада:
   - Кнопка «Вся серия атак» проводит полную серию ударов монстра по цели с учетом КД,
     сопротивлений и индивидуальных спасбросков концентрации в один клик.

6. Аварийное автосохранение боя (Crash Recovery):
   - Автоматическое сохранение слепка активного боя. При перезапуске приложения
     появляется баннер с возможностью восстановить раунд, очередность и хиты.

7. Тактическая карта и второй монитор:
   - Полноэкранный экран игроков (Player Display) без интерфейса мастера.
   - Токены существ, масштабирование под размер (Tiny, Medium, Large, Huge, Gargantuan).
   - Туман войны и скрытие врагов от игроков до обнаружения.

ИНСТРУКЦИЯ ПО УСТАНОВКЕ:
1. Запустите файл Setup.exe из данного архива.
2. Следуйте инструкциям установщика (установка выполняется без необходимости прав
   администратора в папку пользователя или Program Files).
3. Приложение является полностью автономным (Self-Contained x64) и не требует
   предварительной установки .NET Runtime на компьютере.
4. Запустите DnD_AIT через ярлык на Рабочем столе или в меню Пуск.

Приятных игр и захватывающих боевых столкновений!
